# دليل توثيق محرك المحاسبة (`docs/`)

هذا الفهرس **تنظيمي للتنقل** بين وثائق مشروع `accounting_engine`، وليس مصدر حقيقة موحداً. عند التعارض تُرجَّع السلطة المرجعية الموضّحة داخل كل مجال (انظر `quality/DOCUMENTATION_ARCHITECTURE_SPECIFICATION.md`)، وتُسجَّل التعارضات في [`analysis/DOCS_CONFLICT_ANALYSIS.md`](./analysis/DOCS_CONFLICT_ANALYSIS.md).

## هيكل المجلدات ومصادر الحقيقة

| المجلد | الغرض ومصدر الحقيقة |
| --- | --- |
| [`specifications/kernel/`](./specifications/kernel/) | المواصفات المعيارية لمجالات النواة التسعة (`v1.2.0` و`MONEY v2.6.1`) المصاغة وفق `NSM-001`. |
| [`contracts/`](./contracts/) | العقود التشغيلية والتقنية للنواة (الترحيل، الذرية، القفل، منع التكرار، التدقيق، الدقة المالية). |
| [`architecture/`](./architecture/) | المعمارية المستهدفة للنواة، خريطة الحزم، هيكل المشروع، ودليل `pkg/sdk`، و[سجل القرارات المعمارية (`P1`–`P11`)](./architecture/KERNEL_ARCHITECTURE_DECISION_RECORDS.md). |
| [`rules/`](./rules/) | قواعد العمل المحاسبية والهندسية، حصر القدرات، ومعايير القبول والنجاح. |
| [`quality/`](./quality/) | حزمة معيار جودة النواة المحاسبية `v2.0.0` وبوابات الجودة وأدلة التقييم. |
| ~~[`plans/`](./plans/)~~ | ~~الخطط التنفيذية النشطة، خط الأساس، وسجل الفجوات.~~ *(حُذف؛ أُزيلت الروابط الحية إلى الملفات المحذوفة واستُبدلت بنصوص مشطوبة، مع الإحالة إلى التقارير البديلة)* |
| [`analysis/`](./analysis/) | تحليل التضاربات والفجوات التوثيقية؛ [التقرير الحالي](./analysis/DOCS_CONFLICT_ANALYSIS.md) (وثيقة تحليلية وليست قرار اعتماد). |
| [`reports/`](./reports/) | تقارير التحقق النهائي، اعتماد الإصدار، التكافؤ، العزل، وحقن الأعطال. |
| [`operations/runbooks/`](./operations/runbooks/) | أدلة التشغيل والتعافي من الكوارث والتراجع عن الإصدار. |
| [`references/`](./references/) | المرجعية المنهجية لصياغة المواصفات (`NORMATIVE_SPECIFICATION_METHODOLOGY.md`). |
| [`api/`](./api/) | لقطة السطح العام للواجهة (`v1.snapshot`) المستخدمة في فحص توافق الـ API. |
